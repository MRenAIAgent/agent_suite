# LangChain Integration

This directory contains integration with [LangChain](https://www.langchain.com/), a popular framework for building LLM-powered applications.

## Future Implementation

This integration will be fully implemented in a future update, providing:

1. Bidirectional compatibility between LangChain agents and Agent Suite
2. Tools compatibility layer for using Agent Suite tools with LangChain
3. Converters for LangChain tools to use with Agent Suite
4. Benchmark comparison utilities for LangChain and Agent Suite agents

For now, you can use the Agent Suite tools and agents directly.
